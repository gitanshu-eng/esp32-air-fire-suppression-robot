# Autonomous Air-Based Fire Suppression Robot 🔥🤖

## Overview

This project presents an **Autonomous Fire Suppression Robot** designed to detect and extinguish small flames using an air-based suppression mechanism. The robot uses an **ESP32 microcontroller** to process sensor data, control movement, and activate the suppression system.

Flame sensors continuously monitor the surroundings for fire. When a flame is detected, the robot navigates toward the source and activates a **fan-based air suppression system** powered by a DC motor to extinguish the fire. The system integrates sensors, motor drivers, and power modules to enable **autonomous detection, navigation, and suppression**.

## Features

* Autonomous fire detection using flame sensors
* Air-based fire suppression using a fan mechanism
* Autonomous navigation using IR sensors
* Differential drive system using DC geared motors

## Code Working

The program running on the ESP32 controls the robot’s movement, fire detection, and air-based suppression system. The robot continuously reads data from flame sensors and IR sensors to detect fire, navigate the environment, and activate the suppression mechanism when required.

The robot operates in two main modes:

- **Roaming Mode**
- **Fire Tracking Mode**

## 1. Hardware Pin Configuration

At the beginning of the program, all pins connected to the hardware components are defined.

Motor driver pins are used to control the robot’s movement:

- **ENA, ENB** – Motor speed control using PWM  
- **IN1–IN4** – Motor direction control

IR sensors are connected to detect obstacles in the environment.

Multiple flame sensors are placed around the robot to detect the direction of fire:

- **FL** – Far Left  
- **FLM** – Left Middle  
- **FC** – Center  
- **FRM** – Right Middle  
- **FR** – Far Right  

A relay module is connected to control the fan used for air-based fire suppression.

## 2. Motor Control Functions

The code defines several functions that control the movement of the robot.

- `forward()` – moves the robot forward  
- `backward()` – moves the robot backward  
- `turnLeft()` – rotates the robot to the left  
- `turnRight()` – rotates the robot to the right  
- `stopMotors()` – stops all motors immediately  

Motor speed is controlled using PWM signals generated by the ESP32.

The `setSpeed()` function adjusts the speed of both motors using PWM channels.

## 3. Setup Function

The `setup()` function runs once when the robot starts.

During initialization the following tasks are performed:

- Serial communication is started for debugging
- Motor driver pins are configured as outputs
- IR sensors are configured as inputs
- PWM channels are configured for motor speed control
- The relay is initialized and kept OFF

After initialization, the robot is ready to begin its operation.

## 4. Main Loop Operation

The `loop()` function runs continuously and performs the main tasks of the robot:

1. Read sensor values  
2. Detect the presence of fire  
3. Decide robot movement  
4. Activate fire suppression when necessary  

Sensor readings are also printed to the Serial Monitor for debugging purposes.

## 5. Flame Detection

The robot continuously checks readings from all flame sensors.

If any sensor value exceeds a predefined threshold, the system determines that a flame is present.

When this condition occurs, the robot switches from **Roaming Mode** to **Fire Tracking Mode**.

## 6. Roaming Mode (Searching for Fire)

In roaming mode the robot moves around the environment while searching for fire.

Two main operations take place during this mode:

### Obstacle Avoidance

IR sensors detect obstacles in front of the robot.

If an obstacle is detected:

1. The robot moves backward briefly
2. The robot turns right
3. The robot resumes forward movement

This allows the robot to navigate safely through the environment.

### Fire Monitoring

While roaming, flame sensors continuously monitor the surroundings.  
If a flame is detected, the robot switches to **Fire Tracking Mode**.

---

## 7. Fire Tracking Mode

When fire is detected, the robot attempts to move toward the flame.

The robot compares readings from all flame sensors to determine the direction of the fire.

Movement decisions are based on the strongest sensor signal:

- If the **center sensor** detects the strongest signal → robot moves forward
- If the **left sensors** detect a stronger signal → robot turns left
- If the **right sensors** detect a stronger signal → robot turns right

This allows the robot to navigate toward the fire source.

## 8. Fire Reached Condition

The robot determines that it has reached the fire when the flame intensity is very high and the robot is close to the source.

At this point:

- All motors stop
- The extinguishing process begins

## 9. Fire Suppression Process

The relay activates the fan connected to a DC motor, which blows air toward the fire.

The suppression system operates in cycles:

1. Fan turns ON for 5 seconds
2. Fan turns OFF for 2 seconds
3. Sensors check if fire still exists

This cycle repeats until the flame sensors no longer detect fire.

---

## 10. Fire Extinguished

Once the fire is extinguished:

- The relay turns OFF the fan
- The robot moves slightly backward
- The robot turns away from the fire location
- The system returns to **Roaming Mode**

The robot then continues scanning the environment for additional fire sources.
